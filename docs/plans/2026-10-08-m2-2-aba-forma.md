# M2.2 — Aba "Forma e distribuição" (frontend) — plano de implementação

> **Para o agente:** execute tarefa por tarefa, em TDD (Vitest + Testing Library, D58). Antes de escrever código, leia `CLAUDE.md`, `docs/padroes-codigo.md` (§5–§7), specs 09, 15 e 16, `docs/design/telas.md` (tela 4, item **Forma (4e)**), os prints `4e-univariada-forma.png` e `4j-univariada-forma-escuro.png` e os contratos em `docs/plans/2026-10-08-m2-visao-geral.md`.

**Objetivo:** mostrar a aba "Forma e distribuição" na tela 4: cards Assimetria, Curtose, Ajuste à Normal e Ajuste Binomial (ou Bernoulli), nota com os coeficientes de Pearson e a curtose percentílica, frase conjunta, campo "Número de tentativas" para discretas e os gráficos da forma (histograma com curva Normal e QQ-plot; bastões com curva e observado × Binomial).

**Arquitetura:** só a feature `analise`. Funções puras novas em `cartoesForma.ts` (contrato `Forma` → `DefinicaoCartao`), componente `AbaForma` (≤ 150 linhas) com `ControleTentativas` e a grade de figuras reaproveitando `CardGrafico`. `tentativas` entra na URL (D78) e na chave da consulta. O backend decide tudo (aplicabilidade, frases, figuras); a tela só renderiza.

**Branch:** `feat/frontend-forma` (sai de `develop` depois do merge do M2.1) → PR para `develop`. **Prazo sugerido:** 20/10/2026.

### Regras que a tela segue
- A aba aparece entre "Dispersão" e "Gráficos" (ordem de `telas.md`). Desabilitada quando `aplicavel.forma` é falso, com o motivo do item `forma` de `nao_aplicavel` no tooltip (D46); a volta para Frequências já existe (`abaEfetiva`).
- **Cards** (grid de 3, como no print 4e; o 4º card vai para a linha de baixo):
  | Card | Valor | Selo | Interpretação | "Ver fórmula" |
  |---|---|---|---|---|
  | Assimetria | G₁ | "Aprox. simétrica" · "Moderada à direita" · "Forte à esquerda" … | `assimetria.interpretacao` | fórmula `assimetria` + cálculo |
  | Curtose (excesso) | G₂ | "Mesocúrtica" · "Leptocúrtica" · "Platicúrtica" | `curtose.interpretacao` | fórmula `curtose` + cálculo |
  | Ajuste à Normal | "p = 0,21" (`formatarPValor`) | "Compatível com a Normal" / "Afasta-se da Normal" | `normal.frase` | fórmula `normal` + `normal.calculo` (+ linha do complementar) |
  | Ajuste Binomial / Ajuste Bernoulli | "p = …" (Binomial com teste) · "p̂ = 0,3" (Bernoulli ou sem teste) | "Compatível com a Binomial" / "Afasta-se da Binomial" | `frase` | fórmula `binomial`/`bernoulli` + cálculo |
  Ajuste não aplicável → card esmaecido com o `motivo` (print 4e: "Binomial não se aplica a contínuas: …").
- **Nota** abaixo dos cards (como a nota populacional da Dispersão, D80): "Coeficientes de Pearson: As₁ = 0,47 · As₂ = 0,70. Curtose percentílica: K = 0,179 (Normal ≈ 0,263)." — só com os itens aplicáveis; sem nenhum, sem nota.
- **Parâmetros do ajuste** entram na interpretação do card quando existem: "μ̂ = 70,3 · σ̂ = 11,2" / "n = 10 · p̂ = 0,299".
- **Frase conjunta** em `Banner` info abaixo da nota (`forma.interpretacao`).
- **Número de tentativas** (só discreta com Binomial aplicável): `CampoNumero` "Número de tentativas (n)" com ajuda "Padrão: o maior valor observado ({max})." e botão "Aplicar"; valor inválido (não inteiro ou < 1) mostra o erro no campo e não consulta; o erro `TENTATIVAS_INVALIDAS` da API aparece no campo (mensagem + sugestão).
- **Gráficos:** grid de 2 colunas com `CardGrafico` para cada `forma.figuras` (título fora do Plotly, resumo abaixo, D45); sem figuras, nada.
- **Binária:** cards Assimetria e Curtose não aplicáveis (motivo da API), Normal não aplicável, card "Ajuste Bernoulli" com p̂, E[X] e Var na interpretação; sem gráficos.

### Tarefa 6: `AbaForma` e despacho

**Arquivos:** criar `components/AbaForma.tsx`, `AbaForma.module.css`, `AbaForma.test.tsx`; modificar `ConteudoAnalise.tsx` (`PAINEIS.forma = AbaForma`)

Estrutura (≤ 150 linhas; subcomponentes `GraficosForma` e `NotaForma` no mesmo arquivo só se couberem, senão arquivos próprios):
```tsx
export default function AbaForma({ analise, tentativas, aoMudarTentativas }: Readonly<PropsPainel>) {
  const { forma } = analise;
  if (forma === null) return null; // a aba fica desabilitada sem forma (abasDaAnalise)
  return (
    <div className={paineis.aba}>
      <GradeCardsMetrica cartoes={cartoesForma(forma)} formulas={analise.formulas} />
      {controleTentativas(analise, forma, tentativas, aoMudarTentativas)}
      <NotaForma forma={forma} />
      <GraficosForma figuras={forma.figuras} />
    </div>
  );
}
```
O erro `TENTATIVAS_INVALIDAS` chega pelo estado da consulta: `useAnalise` com `tentativas` inválida volta erro — a `PaginaAnalise` já trata `erro`; para mostrar o erro **no campo** e manter a análise anterior, o `estadoDaAnalise` passa a devolver `pronta` com `erroTentativas` quando o erro tem esse código e há dado anterior (teste em `estadoAnalise.test.ts`).
